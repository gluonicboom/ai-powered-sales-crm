// AI-Powered Sales CRM
An AI- powered Customer Relationship Management(CRM) platofrm for small bussinesses to mange, leads, deals, sales activities and follow ups from a single platofrom.

The goal is to make affordable and intellegent CRM that helps small bussinesses spend less time managing sales data and more time closing deals.

//Project Status 
Currently under development

This project is being built as a production-style full-stack application with an AI layer Integrated into core sales workflows.

//Goals
- Manage leads and customer information
- Track deals thorugh a sales pipeline
- provide useful sales analytics 
- Manage  follow-ups and the sales activities
- Uses AI to reduce repetitive work
- Build a scalable multi-user CRM for small bussinesses 

// Planned features in this application
-Total leads
-Active deals
-won and lost deals
-pipeline value
-sales activities
-conversion rate

// AI features

- AI-powered lead scoring
- automatic lead summaries
- sales conversation analysis
